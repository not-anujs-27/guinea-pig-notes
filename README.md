# Guinea Pig Notes

Build a sleek, personal journaling app called DocuVault. Connect it to Supabase using my Project URL and anon key. Users should be able to log in with email/password, add private notes to the 'notes' table, and view public announcements from the 'feed' table. Add this tag to the HTML head: <meta name="secondkey-verification" content="secondkey-proven-target-2026">
